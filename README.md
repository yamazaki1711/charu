# Kira — Читатель китайских текстов со словарём

**Kira** — мобильное приложение для чтения китайских текстов на упрощённых иероглифах с интегрированным китайско-русским словарём БКРС. Опубликовано в RuStore и готовится к публикации в Google Play под этим именем; исходный код и assets (пакет `ru.kira.app`) живут в этом репозитории под прежним кодовым именем `charu` — так исторически называется и сам репозиторий, и internal-классы (`CharuTheme`, `CharuApp` и т.п.), переименование коснулось только пользовательского бренда и Android `applicationId`.

> **Статус (октябрь 2026):** v0.1.1 · полный офлайн-словарь БКРС (**863 740 статей**) + топонимы (548) + личные имена (58 950) · пиньин-аннотации в читалке · новостная лента · адаптация под планшеты · release-сборка подписана, на модерации в RuStore (см. [Releases](../../releases))

## 📱 Возможности

### 🔍 5-уровневая система поиска слов
1. **Локальный БКРС** (863 740 записей) — мгновенный офлайн-поиск
2. **Топонимы** (548 городов) — извлечены из официального дампа 大БКРС по помете `[p]г.[/p]`; без координат (см. ограничения ниже)
3. **Личные имена** (58 950 фамилий и имён) — извлечены из того же дампа по маркерам «(фамилия)» / «(имя собственное)»
4. **Online БКРС** (3.6M записей) — поиск на bkrs.info при наличии сети
5. **Посимвольный пиньинь** — fallback для неизвестных иероглифов

> Топонимы/имена извлечены скриптом
> [`scripts/data_sources/extract_toponyms_names_from_bkrs_dsl.py`](scripts/data_sources/extract_toponyms_names_from_bkrs_dsl.py)
> из официального ежедневного DSL-дампа (bkrs.info/p47) — того же источника,
> что и основной словарь. Ограничение: ~99% этих записей уже есть и в
> основном БКРС (тот же первоисточник), так что каскад обычно отвечает на
> шаге 1; координат топонимов дамп не содержит.

### 📰 Онлайн-новости
- Загрузка статей по RSS, 3 рабочих источника настраиваются в приложении
  (中国生活, 即时新闻, 人民日报时政; по умолчанию включён один — 中国生活).
  Baidu Baijiahao/Sina News/People's Daily — исходные плейсхолдеры в списке
  источников, выключены по умолчанию (html-парсер Baidu не реализован,
  Sina/People's Daily там — не рабочие RSS-эндпоинты)
- Кэш статей — только в памяти на время сессии, не переживает перезапуск
  приложения (offline-кэш на диск — [в планах](#-план-развития-roadmap))
- Сегментация текста с помощью Jieba
- Тап по слову → перевод во всплывающем окне

### 📁 Локальные файлы
- Поддержка форматов: **TXT**, **HTML**, **EPUB**
- Автоопределение кодировки (UTF-8 с BOM, GBK/GB2312 через эвристику; Big5 не поддерживается)
- Сохранение позиции чтения
- Закладки и история

### 📊 Геймификация
- **Ударный режим** — счётчик дней подряд
- **Статистика** — статьи, слова, минуты чтения
- **Выученные слова** — личный словарь с повторениями
- **График активности** — визуализация прогресса

### ⚙️ Настройки
- Выбор темы (системная/светлая/тёмная)
- Регулировка размера шрифта
- Ежедневные напоминания

## 🏗 Архитектура

Проект следует принципам **Clean Architecture + MVVM**:

```
lib/
├── data/                 # Слой данных
│   ├── local/           # SQLite, SharedPreferences
│   ├── remote/          # API, онлайн-сервисы
│   └── repository/      # Реализации репозиториев
│
├── domain/              # Бизнес-логика
│   ├── model/           # Модели данных
│   ├── repository/      # Интерфейсы репозиториев
│   └── usecase/         # Use cases
│
├── presentation/        # UI слой
│   ├── screens/         # Экраны
│   ├── widgets/         # Переиспользуемые компоненты
│   ├── theme/           # Тема (красная, Material 3)
│   ├── navigation/      # Роутинг
│   └── state/           # Riverpod провайдеры
│
└── di/                  # Dependency Injection
```

## 🚀 Быстрый старт

### Требования
- Flutter SDK ^3.11.0
- Dart SDK ^3.11.0
- Android SDK / Xcode (для iOS)

### Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd charu

# Установка зависимостей
flutter pub get

# Генерация тестовой БД (опционально)
dart run scripts/generate_test_db.dart

# Запуск приложения
flutter run
```

### Сборка БД

База данных хранится в `assets/db/charu_bkrs.db`. Для создания полной БД:

```bash
# Использовать готовый скрипт
dart run scripts/generate_test_db.dart

# Или вручную через SQLite
sqlite3 assets/db/charu_bkrs.db < schema.sql
```

### Сборка release-APK

```bash
# Ключ подписи: ~/keystores/charu-release.jks
# Конфигурация: android/key.properties (storePassword, keyAlias, storeFile)

# Сборка (если сборка из ~/Documents зависла — известная проблема
# файлового I/O — используйте копию в /tmp)
rsync -a --exclude build --exclude .gradle --exclude .dart_tool \
  ~/Documents/charu/ /tmp/charu-fix/
cd /tmp/charu-fix && flutter build apk --release

# Верификация подписи
~/Library/Android/sdk/build-tools/36.0.0/apksigner verify \
  --print-certs build/app/outputs/flutter-apk/app-release.apk
```

### Онлайн-словарь
- **bkrs.info** — 大БКРС (3.6M записей)
- Парсинг HTML через Dio + html

### Источники новостей

  настраиваются в Настройках, по умолчанию включён один (中国生活)

  источников, не реализованы (html-парсер под Baidu не написан; URL
  Sina/People's Daily не отдают RSS) — выключены по умолчанию

на использование агрегированной базы, и годы использования этого дампа
сторонними словарными приложениями (GoldenDict-плагины и т.п.) без
претензий — говорят в пользу низкого риска.
