# План: раздел «Библиотека» — бесплатные книги с Wikisource

**Статус:** технический долг, кандидат в следующий релиз (0.2.0). Не начат.
**Дата проработки:** 14 октября 2026. План основан на живой проверке API
Wikisource (октябрь 2026) и аудите текущей архитектуры кода.

---

## Суть фичи

Каталог бесплатных книг на китайском языке (public domain), скачиваемых прямо
в приложение — аналог AoZora Bunko для японского. Источник —
[维基文库 / Chinese Wikisource](https://zh.wikisource.org) (волонтёрский архив
публичного достояния: классика и литература начала XX века, чистый текст,
легальные лицензии PD/CC).

Полного аналога AoZora Bunko для китайского не существует: современная
литература заперта издателями (копирайт КНР — жизнь + 50 лет), а классика
размазана по проектам. Wikisource — лучший кандидат: структурированные
данные + API. Дополнительные источники (ctext.org — только 文言文,
Project Gutenberg — китайский раздел мал) в скоуп не входят.

## Результаты разведки (октябрь 2026)

1. **Текст достаётся просто.** `action=parse&prop=text` отдаёт HTML
   произведения; `mw-parser-output` + вырезание служебных блоков → чистый
   текст. Проверено на «故乡» Лу Синя: 31 КБ HTML → чистая проза.
   Страницы авторов (`作者:魯迅`) содержат готовые списки произведений по
   жанрам — основа для кураторского каталога.
2. **Wikisource НЕ конвертирует контент в упрощённые иероглифы** — ни
   `variant=zh-cn`, ни REST `Accept-Language`, ни веб-страница. Принцип
   фидельности первоисточнику: тексты традиционные. Решение — клиентская
   конвертация t→s через OpenCC при скачивании.
3. **Конвертер для Flutter есть и живой:**
   [`flutter_open_chinese_convert`](https://pub.dev/packages/flutter_open_chinese_convert)
   (обновляется, ~1–2 МБ словарей — незаметно на фоне БКРС).
4. **Архитектурная разведка кода** (ключевое):
   - Конвейер чтения переиспользуется целиком: книга = файл + строка в
     `reading_history` → `ReaderScreen`, позиция, закладки, минуты, streak,
     SRS работают без правок читалки.
   - `news_api_service.dart` — образец для Dio-сервиса, включая прокси-цепочку
     `'' → allorigins → codetabs` (пригодится для доступа к Wikisource).
   - `charu_user.db` сейчас `version: 1` без `onUpgrade` — первая миграция
     потребуется для таблицы книг.
   - `path_provider` в зависимостях нет — добавить (хранение скачанных книг).
   - Пятая вкладка = запись в `AppShell._tabs` + `GoRoute` в `app_router.dart`.

## Дизайн

### Каталог — встроенный ассет, не поиск

`assets/library/catalog.json` с кураторской подборкой 40–60 **одностраничных**
произведений: рассказы и эссе Лу Синя, Zhu Ziqing (背影, 荷塘月色), Yu Dafu,
三字经 / 弟子规, басни, стихи — с метаданными (автор, год, жанр, примерный
уровень сложности, `wikisourceTitle`).

Почему не поиск по Wikisource в MVP: каталог работает офлайн, качество
текстов гарантировано ручным отбором, модерация RuStore получает
предсказуемое приложение. Переводы иностранных произведений не включать
(права переводчика), только китайский оригинальный public domain.

### Скачивание

`WikisourceService` (Dio, по образцу `NewsApiService`):

1. GET `w/index.php` / API `action=parse&prop=text` для страницы произведения.
2. Чистка HTML: навигация, `headertemplate` («本作品收錄於…»), блок
   «姊妹计划», `span.pagenum` (номера страниц ProofreadPage), `printfooter`.
3. Конвертация OpenCC t→s (тумблер в настройках: «Сохранять традиционные
   иероглифы», по умолчанию выключен — конвертируем).
4. Сохранение UTF-8 txt в `<documents>/books/<id>.txt`.
5. Запись в БД + `reading_history` (см. ниже).

### Хранение

- Новая таблица `library_books` в `charu_user.db`: `id`, `wikisource_title`,
  `author`, `title_display`, `file_path`, `format='txt'`, `downloaded_at`,
  `char_count`, `source_url`. **Первая миграция проекта**: поднять `version`
  до 2, добавить `onUpgrade` (создание таблицы при 1→2).
- Дублирующая запись в существующую `reading_history` (`path` = путь к файлу,
  `name` = «Автор — Произведение») — читалка, прогресс и статистика
  подхватывают книгу без единой правки.
- Удаление книги: удалить файл + обе записи.

### UI

Пятая вкладка «Библиотека»:

- Экран каталога: карточки по авторам/уровням, фильтр по встроенному каталогу;
  пометка «скачано».
- Экран книги: метаданные, кнопка «Скачать» (прогресс) → «Читать» →
  `context.push('/files/reader', extra: {path, name})`.
- Оффлайн: каталог доступен всегда; скачивание требует сеть один раз.

## Риски и подводные камни

| Риск | Митигция |
|---|---|
| Разнородные шаблоны Wikisource → мусор в тексте | Каталог зафиксирован вручную: каждый текст прогоняется глазами при отборе |
| Качество конвертации t→s | OpenCC с фразовыми словарями — высокое для литературы; тумблер «оставить традицию» как страховка |
| Прокси-фоллбеки могут умереть | Переиспользовать цепочку из новостей; скачивание разовое, не фоновое |
| Первая миграция БД | Простая (CREATE TABLE при 1→2), протестировать на чистой установке и поверх 0.1.1 |
| С ростом каталога — ручная вычитка | Скоуп ограничен 40–60 текстами; расширение — отдельной итерацией |
