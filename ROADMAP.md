## 🐛 Известные проблемы

### Критичные
- [x] Отсутствует проверка сетевого подключения — исправлено: DNS-пробник перед online-поиском (см. выше)
- [x] Нет обработки ошибок сети для online-словаря — исправлено: попап показывает «Нет подключения к интернету», а не generic «Перевод не найден»
- [x] Encoding detection работает только для UTF-8 — на деле уже была эвристика UTF-8 BOM/GBK/GB2312 (`file_repository_impl.dart`); этот пункт был просто неактуальным. Big5 по-прежнему не поддерживается (не требуется — весь контент приложения на упрощённых иероглифах)
- [x] Кнопки «Очистить историю» / «Сбросить прогресс» в Настройках ничего не делали (TODO-заглушки, показывали success-снэкбар без реального удаления) — теперь реально чистят `reading_history` / `user_vocabulary`+`daily_stats`+`streak_data`
- [x] Экран чтения локальных файлов (`reader_screen.dart`) не был обёрнут в скролл — длинный TXT/EPUB физически нельзя было прокрутить; `saveReadingPositionUseCaseProvider` существовал в DI, но нигде не вызывался — исправлено, позиция восстанавливается при повторном открытии файла
- [x] Закладки (`_addBookmark`) были заглушкой — теперь реально пишут в таблицу `bookmarks` (списка/перехода по закладкам в UI пока нет)

### Средние
- [ ] Нет индикатора загрузки при открытии больших файлов
- [ ] Отсутствует поиск по сохранённым словам
- [ ] Нет подтверждения при сбросе прогресса

### Мелкие
- [x] Print-statements в production коде — заменены на `log()` (`lib/core/log.dart`), гейтится `kDebugMode`, ничего не пишется в release
- [x] Не используются логгеры — единая точка логирования вместо разрозненных `debugPrint`
- [ ] Отсутствуют unit-тесты
- [ ] Нет интеграционных тестов
