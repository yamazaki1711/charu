## 🐛 Отладка

### Если БД не загружается

**Проблема:** Ошибка "database does not exist"

**Решение:**
```bash
# Перегенерировать БД
dart run scripts/generate_test_db.dart

# Проверить путь
dir assets\db\charu_bkrs.db

# Clean и rebuild
flutter clean
flutter pub get
flutter run
```

### Если слова не находятся

**Проблема:** Поиск возвращает "Перевод не найден"

**Решение:**
1. Проверить данные в БД:
   ```bash
   # Через SQLite
   sqlite3 assets\db\charu_bkrs.db "SELECT * FROM dictionary LIMIT 5;"
   ```

2. Проверить запрос:
   ```dart
   // В DictionaryRepositoryImpl
   print('Searching for: $word');
   ```

### Если сегментация не работает

**Проблема:** Текст не подчёркнут, тап не работает

**Решение:**
1. Проверить инициализацию Jieba:
   ```dart
   await JiebaSegmenter.init();
   ```

2. Проверить путь к словарю Jieba:
   ```yaml
   # pubspec.yaml
   assets:
     - assets/jieba/
   ```
