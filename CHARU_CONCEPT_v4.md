# CHARU — Концепция проекта v4.0

**Читатель китайских текстов с интегрированным словарём**

* **Версия**: 4.0 (Unified)
* **Дата**: 20 февраля 2026
* **Платформа**: Кроссплатформенная (Android + iOS) на базе **Flutter**
* **Среда разработки**: **Antigravity** с использованием **Stitch MCP** и **Flutter MCP**

---

## 1. ОБЩАЯ ИНФОРМАЦИЯ

### 1.1 Название и назначение

**CHARU** (читается "чару") — мобильное приложение для чтения китайских текстов на упрощённых иероглифах с интегрированным китайско-русским словарём БКРС. Разработка ведётся через ИИ-агентов в среде Antigravity, что позволяет быстро итерировать дизайн и функционал.

### 1.2 Целевая аудитория

* Носители русского языка, изучающие китайский
* Уровень: от начального до продвинутого
* Платформа: Android и iOS (смартфоны и планшеты)

### 1.3 Ключевая особенность

Мгновенный доступ к переводу любого слова одним касанием с отображением пиньиня и перевода. Приложение спроектировано для коротких сессий (10–15 минут) в повседневных паузах — в транспорте, в очереди, в ожидании.

### 1.4 Продуктовая философия

У людей мало времени на полноценное чтение. CHARU делает ставку на **микросессии**: актуальные новости на китайском, которые можно прочитать за 10–15 минут. Приложение мотивирует возвращаться через систему прогресса, счётчик ударного режима и визуальную статистику.

## 2. ТЕХНОЛОГИЧЕСКИЙ СТЕК

### 2.1 Среда разработки (AI-Driven)

Вместо ручного написания кода используется связка инструментов от Google, управляемая через MCP (Model Context Protocol):

**Google Stitch (Designer):**
* Генерирует интерфейсы по текстовому описанию
* Использует модель Nano Banana для генерации уникальных ассетов и иконок
* Позволяет визуально настраивать стиль через аннотации

**Antigravity (Developer):**
* Агентская платформа, управляющая процессом сборки
* Доступ к моделям: Qwen 3.5, Claude Sonnet 4.6, Gemini 3 High
* Использует Stitch Skill для импорта дизайнов и превращения их в структуру приложения
* Автоматически разрешает зависимости (Flutter SDK, Android SDK)

**Flutter MCP (Framework):**
* Обеспечивает связь Antigravity с фреймворком Flutter
* Позволяет агенту выполнять hot reload, запускать тесты и собирать APK/IPA

## 6. СЛОВАРЬ И РАБОТА С ТЕКСТОМ

### 6.1 Система поиска слова (5 уровней)

```
Пользователь тапнул слово
    ↓
1️⃣  ЛОКАЛЬНЫЙ БКРС (офлайн, ~250k записей)
    ↓
    Найдено? → ДА → Показать перевод на русском
    ↓ НЕТ
2️⃣  БАЗА ТОПОНИМОВ (офлайн, OSM/GNS, ~100k записей)
    ↓
    Найдено? → ДА → Показать [🗺️] + пиньинь + название
    ↓ НЕТ
3️⃣  БАЗА ИМЁН (офлайн, ~20k записей)
    ↓
    Найдено? → ДА → Показать [👤] + пиньинь
    ↓ НЕТ
4️⃣  大БКРС ОНЛАЙН (bkrs.info, 3.6М записей)
    только если устройство online
    ↓
    Найдено? → ДА → Показать перевод на русском + [🌐]
    ↓ НЕТ или OFFLINE
5️⃣  FALLBACK: Посимвольный пиньинь
    ↓
    Показать пиньинь каждого иероглифа + [❓]
```

**Почему CC-CEDICT исключён:**
Офлайн БКРС содержит ~250k записей, CC-CEDICT — лишь ~124k. Если слово не найдено в 250k русских записях, вероятность найти его в 124k английских ничтожно мала. CC-CEDICT не добавляет ценности при наличии 大БКРС онлайн с 3.6М записей на русском языке.

**Почему 大БКРС онлайн:**
* 3 600 000 записей — на порядок больше офлайн-базы
* Живой словарь, пополняется пользователями постоянно
* Русский язык — без промежуточного перевода
* Бесплатный для некоммерческого использования

### 6.2 Всплывающее окно словаря

**Дизайн-принцип:** Современный визуальный стиль (Liquid Glass) с приоритетом читаемости CJK-текста. Фон карточки словаря — плотный, непрозрачный для максимальной разборчивости иероглифов. Размытие (blur) применяется к фоновому затемнению экрана, а не к самой карточке.

### 6.3 Сегментация китайского текста

**Проблема:** В китайском нет пробелов между словами.
```
我今天去了图书馆 ← слитный текст
```

**Решение:** Библиотека Jieba (C++ через FFI или Dart-порт).
```
我 / 今天 / 去了 / 图书馆 ← сегментированный
```

**Применение:**
* При открытии текста — автоматическая сегментация
* При тапе — определяется слово целиком (не один иероглиф)
* Результат кэшируется для производительности

## 8. ГЕЙМИФИКАЦИЯ И ПРОГРЕСС (NEW)

### 8.1 Философия

Приложение рассчитано на микросессии (10–15 минут). Чтобы пользователь возвращался каждый день, необходима система мотивации, которая делает прогресс видимым и вознаграждает регулярность.

### 8.2 Счётчик ударного режима

* Считает количество дней подряд, когда пользователь провёл хотя бы одну сессию чтения
* Минимальная сессия для засчитывания: прочитана 1 статья или 5 минут чтения файла
* Отображается на главном экране: 🔥 3 дня подряд
* При потере ударного режима — мягкое сообщение без осуждения, предложение начать заново

## 10. ДИЗАЙН: LIQUID GLASS

### 10.1 Ключевой принцип

**Современный визуальный стиль с абсолютным приоритетом читаемости CJK-текста.** Эффекты Liquid Glass (размытие, полупрозрачность) применяются к декоративным и навигационным элементам, но **не** к областям, где отображаются иероглифы, пиньинь и перевод. Текстовые области всегда имеют плотный контрастный фон.

### 10.2 Где применяется Liquid Glass

| Элемент | Blur | Alpha | Примечание |
|---------|------|-------|------------|
| Bottom Navigation | 20px | 0.8 | Декоративный элемент |
| Фоновое затемнение при попапе словаря | 30px | 0.5 | Фон за карточкой |
| Карточки новостей (фон) | 15px | 0.75 | Только фон карточки, текст на плотной подложке |
| Модальные окна (фон) | 35px | 0.7 | Фон за модалкой |

### 10.3 Где Liquid Glass НЕ применяется

* Карточка словаря (всплывающее окно) — плотный фон для читаемости иероглифов
* Экран чтения (текст статьи/файла) — чистый фон без эффектов
* Любые области с CJK-текстом мелкого размера

### 10.4 Цветовые схемы

**Светлая тема (по умолчанию):**
```
Фон:                     #F8F9FA (светло-серый)
Текст:                   #1A1A1A (почти чёрный)
Liquid Glass фон:        rgba(255, 255, 255, 0.75)
Liquid Glass граница:    rgba(255, 255, 255, 0.2)
Акцент:                  #FF6B6B (мягкий красный — отсылка к Китаю)
```

**Тёмная тема:**
```
Фон:                     #1A1D23 (тёмно-серый)
Текст:                   #E8E8E8 (светло-серый)
Liquid Glass фон:        rgba(30, 33, 40, 0.75)
Акцент:                  #FF8585 (светлый красный)
```

### 10.5 Stitch-промпт для генерации дизайна

```
"Build a mobile reading app with Liquid Glass style. Semi-transparent 
cards for navigation elements (blur 15-20px, alpha 0.75), thin white 
borders. Text content areas must have solid opaque backgrounds for 
maximum CJK character readability. Dark theme with soft red accent 
(#FF6B6B). Bottom navigation with blur effect. Chinese text should 
use large clear font (minimum 18sp for body text)."
```

Итерации уточняются аннотациями в интерфейсе Stitch, после чего Antigravity обновляет Flutter-код.
